Build a full-stack project named NeuroRoute-SDN that implements a research paper on proactive SDN routing. Backend: Python 3.11 on native Windows 10/11, a SimPy discrete-event SDN simulator (primary backend) behind a NetworkBackend interface plus an optional Mininet and Ryu backend inside WSL2, PyTorch, PyTorch Geometric (GATConv), NetworkX (Yen k-shortest paths), FastAPI with WebSocket, SQLite via SQLAlchemy. Frontend: React 18 + Vite + TypeScript + Tailwind CSS + shadcn/ui + lucide-react icons + Recharts + React Flow (topology) + Zustand + TanStack Query. Implement: (a) a topology loader (NSFNET 14 nodes, Abilene 11 nodes, small 7-switch demo) with link bandwidth/delay settings; (b) a simulated OpenFlow-style controller (flow tables, port and queue stats, rule and queue-rate installation, with a Ryu equivalent for the WSL2 backend) that discovers topology, polls port and queue stats every 1 second, installs flow rules and queue (HTB) configs via REST; (c) traffic generator producing Latency-Sensitive (LS, bursty Poisson, small UDP packets) and Throughput-Sensitive (TS, constant rate) flows using the simulator's own generators (iperf3 only in the WSL2 backend); (d) data collector storing per-switch queue occupancy time series; (e) preprocessing per paper Eq. 3 (dense timing indicator, tanh normalisation); (f) GAT-GRU model (multi-head GATConv, then GRU cell, then dense k-step-ahead head, MSE loss); (g) D3QN agent (state = current + predicted occupancy along Yen's candidate paths, dueling streams, double-Q target, replay buffer, target sync every L steps); (h) tabular Q-learning queue-rate agent (reward = eta * (C - occupancy)); (i) baselines: static Dijkstra, ECMP, LSTM+Q-learning, Chebyshev-GCN+DQN; (j) a proactive control loop exactly following Algorithm 1 of the paper; (k) REST + WebSocket API; (l) a dashboard with the pages specified below. Provide PowerShell scripts (setup.ps1, start_dev.ps1, run_all.ps1) instead of a Makefile, optional Docker Desktop with the WSL2 backend, a README, unit tests, and a script that runs every experiment and exports CSV plus charts. Everything in the primary mode must run natively on Windows 10/11 with no Linux, WSL2 or VM: use pathlib for all paths, DataLoader num_workers=0, and a main-module guard around multiprocessing code.
